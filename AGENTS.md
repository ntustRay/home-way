## Shared authentication

Use the published @ntustray/web-authentication-component npm package for authentication UI, state and provider adapters. Read its README and API before changing a login flow. Keep the existing identity service, account IDs, callbacks and server-side authorization. Existing passwords may be shorter than the new-password policy. Fix reusable behavior in the package and then update the dependency and lockfile here. Set locale explicitly for this application. Verify account switching, failed sign-out and private-data isolation.
